3.1 Ramas

Una rama es un puntero a un commit: trabajo paralelo sin tocar la rama principal

git switch -c feature/new-rama

3.2 Fusiones

Fast-forward, fusión de tres vías, squash y rebase integran el trabajo de las ramas.Trabajo en distintas ramas y colaboradres

git merge feature/nueva-idea
